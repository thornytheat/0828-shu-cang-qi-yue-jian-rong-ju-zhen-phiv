# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 producer, reader, gate。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `field`、`data_type`、`scale`、`nullable`、`has_default` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

类型 1 为 int32，2 为 int64，3 为文本，4 为 Decimal。Decimal 的整数位在生产者和读取器之间固定，只比较小数位。默认值只供缺列回填，不能覆盖生产者明确写入的 null。字段由稳定编号匹配。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
